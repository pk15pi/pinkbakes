# Free 3D model licenses (PinkBakes)

All models downloaded for this folder are under **CC0 1.0 Universal (Public Domain)** or equivalent public-domain dedication allowing free commercial use without attribution.

## Sources

1. **Kenney Food Kit** — https://kenney.nl/assets/food-kit — CC0-1.0 — ~200 GLB food models + shared `Textures/colormap.png`
2. **Kenney Holiday Kit** (sweets subset) — https://kenney.nl/assets/holiday-kit — CC0-1.0 — candy canes, gingerbread
3. **Tiny Treats – Baked Goods** (Isa Lousberg) — https://opengameart.org/content/tiny-treats-baked-goods-set — CC0-1.0 — cakes, pies, donuts, etc. (GLTF + atlas texture)
4. **Poly Pizza** (CC0-tagged models only) — https://poly.pizza — Public Domain (CC0) — individual dessert/food GLBs from Kenney, Quaternius, Isa Lousberg, and others (deduplicated against Kenney pack by content hash)

## Notes

- Prefer `.glb` when both formats exist.
- Kenney Food Kit GLBs reference `Textures/colormap.png` relative to the model file — keep that path when loading.
- Tiny Treats `.gltf` files reference `tiny_treats_texture_1.png` in the same folder.
- Attribution not required under CC0 but appreciated by authors.
- Sketchfab and login-walled downloads were skipped.
